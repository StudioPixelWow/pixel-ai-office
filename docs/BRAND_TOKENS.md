# Pixel — Design Tokens (נלמד מ-s-pixel.co.il, 30.10.2026)

שפת המותג: **גרדיאנט תכלת + צהוב זוהר** על לבן, עם בלוקים כהים (ink). אין ורוד/מג׳נטה בשפת המותג.

> הערה: משתני `--e-a-color-*` (ורוד #f3bafd וכו׳) שמופיעים בעמוד שייכים לממשק העורך של Elementor ולא לאתר — אין להשתמש בהם.
